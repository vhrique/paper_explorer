# Paper Reader — frontend

This is the (only) app package. See the [root README](../README.md) for what
the app does, how to run it, and configuration, and [CLAUDE.md](../CLAUDE.md)
for architecture details.

```bash
npm install
npm run dev            # Vite dev server at http://localhost:5173
npm run build          # production build
npm run electron:dev   # Electron + Vite together
npm run electron:dist  # packaged desktop installers → release/
```
